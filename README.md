# lany-typography-prompts-skill

为 Lany 小生的封面、Banner、卡片和配图编写中文标题字形与字效提示词，必要时生成并校准文字图。聚焦图片里的文字视觉；不用于撰写文章正文或通用字体百科。

## 独立仓库安装

本仓库包含 `lany-typography-prompts` 技能及其参考资料与资源，支持独立安装。依赖可读取 SKILL.md 的 Agent；实际生图需要宿主提供图片生成工具。

```sh
git clone https://github.com/LanyXiaosheng/lany-typography-prompts-skill.git ~/.codex/skills/lany-typography-prompts
```

若目标目录已存在，请先检查其中的自定义内容。安装后重新加载技能，调用 `$lany-typography-prompts`。完整工作流见 [SKILL.md](SKILL.md)。
